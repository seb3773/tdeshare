How to use TDE Samba Shares:

  • From your File Manager: Right-click any folder in Konqueror, Dolphin, or Krusader and select Share....
  • From the Application Menu: Go to Application Menu → Settings → System → TDE Samba Shares.
  • From Terminal: Type tdeshare or tdeshare /path/to/folder.

Tip: If you were newly added to the sambashare group, you may need to log out and back in to your Trinity session for group permissions to take full effect desktop-wide.
