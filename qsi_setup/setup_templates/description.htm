TDE Samba Share Manager (tdeshare) is a native, lightweight graphical utility designed for Q4OS / Trinity Desktop Environment (TDE) to manage user network shares without editing configuration files or requiring root privileges.

Key Features:

  • Simple & Safe: Share any local folder easily using Samba's native usershare engine.
  • Granular Permissions: Configure read-only, full access (read/write), or custom multi-user ACLs.
  • File Manager Integration: Adds a Windows-style "Share..." action to the right-click menu of Konqueror, Dolphin, d3lphin, and Krusader.
  • Filesystem Health Checker: Inspects Unix permissions and assists with 1-click permission fixes.
  • Global Samba Options: Configure Workgroup name, disk quota simulation, and network recycle bin (.recycle).
